# Project: Lunar Beacon — Last Relay (`starforge_ark_cradle`)

## Architecture
- **Core Stack**: TypeScript 7 + Three.js (`^0.187.0`) + GSAP (`^3.15.1`) + Web Audio API procedural synthesizer + Vite 8 (`tsc && vite build`, plus programmatic IIFE standalone bundler `bundle_standalone.mjs`).
- **Module Boundaries**:
  - `src/types.ts`: Shared domain & 3D rig types (`GameMode`, `TowerType`, `TowerTier`, `TowerRig`, `EnemyRig`, `StationEnvironment`).
  - `src/config/gameConfig.ts`: Authoritative map path, 10 build pads, 3 tower × 4 tier blueprints, 5 enemy/Elite/Boss blueprints, 8 wave definitions, economy & victory reward constants.
  - `src/render/ToonMaterials.ts`: 4-step `NearestFilter` discrete `MeshToonMaterial` ramps + custom Fresnel tier rim shader + world/faction color palette.
  - `src/render/ToonOutlineComposer.ts`: Multi-pass WebGL2 `1.5x` supersampled MSAA pipeline (Pass 1 Layer-0 view-normal+depth -> Pass 2 Layer-0 solid toon -> Pass 3 `#1A1033` silhouette/seam outline with `grazing^3` slope compensation -> Pass 4 Layer-1 & `vfxScene` un-outlined overlays -> Pass 5 output blit).
  - `src/render/TowerFactory.ts`, `EnemyFactory.ts`, `BeaconAndPropsFactory.ts`: 100% procedural 3D chunky cartoon mech models, lunar facility slab diorama, Return Beacon, 3DSupply Crate, 3D beveled Gold Coins, and 3D faceted Energy Crystals.
  - `src/fx/VfxManager.ts`: Projectiles, parabolic mortar shells, shockwave rings, sparks, 3D armor-break debris, 3D fountaining loot, Boss warning zone, and disposal lifecycle.
  - `src/game/CinematicDirector.ts`: GSAP choreography for all 5 mandatory presentation stages (Stage 1 fly-in & sequential lamp boot, Stage 2A 3-beat build, Stage 2B non-pausing arc-fly T2/T3 upgrade, Stage 2C simulation-pausing T4 golden hero reveal, Stage 3 Boss fissure/suction/silence/slam entrance, Stage 4 climax bursts & Boss chain explosions, Stage 5 Beacon sky-beam, crate drop & clasp-popping 3D loot fountain).
  - `src/game/GameEngine.ts`: Simulation loop, camera framing (desktop widescreen & mobile portrait), raycasting, combat targeting/damage/slow/stun/weakpoint, economy, wave spawning, and `window.__LUNAR_BEACON_GAME__` test/telemetry hook.
  - `src/audio/AudioManager.ts`: Pure WebAudio procedural SFX with rate-limiting, dynamics compression, and persistent mute toggle.
  - `src/ui/UIManager.ts`, `src/main.ts`, `src/style.css`: Tactile industrial enamel HUD, 3-step onboarding, build/upgrade/sell cards, victory/defeat overlays, responsive mobile portrait HUD, and adaptive `<agent-embed>` (`580px` zero-collapse) vs full-viewport (`100%` top-window / `:5173` / side-pane) container sizing.

## Interface Contracts

### Contract 1: `M1 (src/types.ts, TowerFactory.ts)` ↔ `M2 (GameEngine.ts, CinematicDirector.ts)`
- `TowerRig` (`src/types.ts`):
  - Preserves all existing properties (`root`, `baseGroup`, `turretYaw`, `weaponPitch`, `muzzlePoints`, `recoilingBarrels`, `rotatingRings`, `hingedFlaps: THREE.Object3D[]`, `specialGear`, `coreMaterial`, `tierTrimMat`, `tierGroups`, etc.) for 100% backward compatibility.
  - Adds optional `idleCore?: THREE.Object3D` on `TowerRig` (populated for all 3 tower types in `TowerFactory.ts`: `coreGem` on `autocannon`, `tierCore` on `mortar`, `magInnerCore` on `magnetic`).
  - Every `flap` pushed into `rig.hingedFlaps` sets `flap.userData.hingeAxis = 'x' | 'y' | 'z'` and `flap.userData.openAngle = number` (signed open radian target, e.g., `-0.55` for Autocannon `'x'` vents/louvers, `sx * 0.62` for Mortar `'y'` doors, `0.48` for Magnetic `'z'` radial petals) plus `flap.userData.restAngle = flap.rotation[axis]`.
  - Magnetic Tower (`TowerFactory.ts`) attaches its upper ring/core emitter group inside `weaponPitch` (at rest `z = 0`, `y = ...` matching original world position) so `weaponPitch.children.length > 0` and Stage 2A's 3rd mount beat animates it cleanly.
  - `TowerFactory.ts` exports `applyTowerTierVisuals(rig: TowerRig, tier: TowerTier, options?: { visibilityOnly?: boolean }): void` (or adds `setTowerTierVisibility(rig: TowerRig, tier: TowerTier): void`) so `CinematicDirector` can reveal `t2`/`t3`/`t4` meshes at `t = 0` for arc fly-in while deferring `applyTowerTierVisuals(rig, newTier)` color/rim switch until `lockEnd` / `climaxAt`!

### Contract 2: `M1 (VfxManager.ts)` ↔ `M2 (CinematicDirector.ts)`
- `VfxManager` adds `public spawnChestOpenCelebration(worldPos: THREE.Vector3): void` which triggers expanding golden/cyan ground shockwave rings (`spawnGroundRing`) + radial celebratory sparks (`spawnHitSparks` / fountain sparkles) WITHOUT spawning a tall `AdditiveBlending` vertical cylinder over `worldPos`, preserving crisp cel-shaded contrast on the open chest, coins, and crystals.

### Contract 3: `M1 (ToonOutlineComposer.ts)` ↔ `M2 (GameEngine.ts)` & `E2E`
- `ToonOutlineComposer.setSize(cssWidth, cssHeight)` sets `renderer.setPixelRatio(1)` and `renderer.setSize(this.ssWidth, this.ssHeight, false)` (`1.5x` CSS resolution, never multiplying `window.devicePixelRatio`), keeping `<canvas>` CSS layout dimensions at `100% x 100%` (`cssWidth x cssHeight`) via `updateStyle = false`.
- Any screen-space projection or pointer raycasting in `GameEngine.ts` or E2E tests MUST read CSS viewport bounds (`canvas.clientWidth` / `canvas.clientHeight` or `canvas.getBoundingClientRect()`), NOT `canvas.width` / `canvas.height` (which is `1.5x` supersampled).
- Solid 3D silhouettes and inner normal seams output `#1A1033` (`rgb(26, 16, 51)` ± 4 per channel tolerance in sRGB) without ACESFilmic purple-black crush (`#150628`).

### Contract 4: `M2 (GameEngine.ts & DOM)` ↔ `E2E (tests/e2e_tiers.mjs)`
- Public entry points & opaque-box hooks preserved (do NOT rename existing DOM IDs or `window.__LUNAR_BEACON_GAME__` read/control methods):
  - DOM IDs: `#app`, `#game-canvas`, `#onboarding-guide`, `#hud-gold`, `#hud-crystals`, `#hud-hp`, `#hud-wave`, `#hud-kills`, `#btn-speed`, `#btn-mute`, `#btn-pause`, `#btn-start-wave`, `#build-tray`, `.build-card[data-tower="autocannon"|"mortar"|"magnetic"]`, `#tower-panel`, `#btn-upgrade-tower`, `#btn-sell-tower`, `#upgrade-stamp`, `#legendary-banner`, `#boss-alert`, `#victory-screen`, `#btn-claim-rewards`, `#btn-play-again`, `#defeat-screen`, `#btn-retry-defeat`, `#pause-modal`, `#btn-resume`, `#btn-restart-pause`.
  - `window.__LUNAR_BEACON_GAME__`: preserves existing state snapshot/projection helpers (`getState()`, `projectWorldToScreen(x, y, z)`, pad screen projection, etc.) used by Playwright tests to drive genuine UI clicks/taps and inspect game state without internal module imports.
